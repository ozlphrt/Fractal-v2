# Fractal Studio v2

WebGL2 raymarching studio with 20 fractal formulas, a material/lighting/optics editor, keyframe loops and an auto-play tour.

**Live:** https://ozlphrt.github.io/Fractal-v2/

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
```

## Controls

- Drag: orbit · Right-drag / Shift-drag / two-finger drag: pan · Wheel / pinch: zoom · Double-click: recenter
- Dock: ▶ plays the auto-tour (pauses when you grab the camera) · sliders icon opens settings
- Settings drawer: Optics, Lighting, Materials, Fractal Math, plus a global keyframe loop (export/import as JSON)
